# Linear-Regression-Machine-Learning
In this repository, I learn how to use and implement surface level machine learning algorithms like a linear regression model. The "Learning Linear Regressions" folder contains projects that I've made when I was first learning how to make a linear regression model. Here, I learned how to implement these machine learning models properly with correct syntax. Then, in the "Linear Regression Project" folder I have, I submitted a summative project where I use an external dataset (which I found from Kaggle), and then implement a linear regression machine learning model on the dataset. This allows me to make data-driven predictions using the model. Overall this repository outlines the steps I took to learn how to use linear regression models and then highlights a project in which I used this machine learning algorithim to effectivelty analyze and make informed predictions using an external dataset.

# Linear-Regression-Machine-Learning
In this repository, I learn how to use and implement surface level machine learning algorithms like a linear regression model. The "Learning Linear Regressions" folder contains projects that I've made when I was first learning how to make a linear regression model. Here, I learned how to implement these machine learning models properly with correct syntax. Then, in the "Linear Regression Project" folder I have, I submitted a summative project where I use an external dataset (which I found from Kaggle), and then implement a linear regression machine learning model on the dataset. Additionally, I included KNeigbors Regressor, Random Forest Regressor, and Support Vector Machine (SVM). By including these additional regression models in my project, I was able to compare how accurate the Linear Regression model was compared to other regression models that took different approaches towards creating an accurate regressor. In the end, I compared multiple metrics across the models including MSE, R², RSME, and MAE. Using these metrics, I identified the most accurate and representative model of the dataset. This allowed me to make more efficient data-driven predictions on the dataset. Overall this repository outlines the steps I took to learn how to use linear regression models and then highlights a project in which I used this machine learning algorithim as well as multiple others to effectively analyze and make informed predictions using an external dataset.
